# Homestead BIM

Homestead BIM is a building design (BIM) tool by Bhururu (Pvt) Ltd, Zimbabwe, part of the Zezuru family
([zezuru.digital](https://zezuru.digital)). Draw walls, doors, windows, roofs, stairs and rooms on a level plan and see
the same model in 3D, in elevations and sections, in schedules and on sheets.

This repository holds the **downloads and updates** of the app, and its **issues**.

## Downloads

Every version is on the [Releases](../../releases) page:

- **Windows:** the installer (`.exe`), or the Microsoft Store packages (`.appx`)
- **macOS:** `.dmg` and `.zip`
- **Linux:** AppImage (updates itself), `.deb` and `.rpm`
- **Android tablets:** `.apk` (Google Play to follow)
- **Claude Desktop extension:** `.mcpb`
- **Homestead Link for Revit** (2022 to 2027): `.zip`

Installed copies of Homestead check this page for updates by themselves.

## Problems and ideas

Open an [issue](../../issues). In the app, **Help > Report a problem** fills one in for you; your project is never
attached.
